# ⌚ TIMEZONE — Every Second Counts

A modern, responsive e-commerce web application for a premium watch store. Explore collections for men, women, and kids, discover new arrivals, apply price filters, and manage your wishlist.

---

## 🌟 Features

- **🏠 Hero & Brand Showcase**: Engaging hero banner and brand presentation.
- **🏷️ Product Categories**: Dedicated sections for Men, Women, Kids, and New Arrivals.
- **🔥 Mega Sale**: Highlighted promotional and discounted watch deals.
- **🔍 Search & Filter**: Search watches by keyword and filter collections by price.
- **❤️ Wishlist**: Dedicated page to save and review favorite timepieces (`wishlist.html`).
- **🔐 User Authentication**: Clean UI for user sign-in (`login.html`) and registration (`register.html`).
- **📱 Fully Responsive**: Optimized for desktop, tablet, and mobile screens.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic and accessible page structure.
- **CSS3**: Custom styling, layout design, and responsive media queries.
- **JavaScript (ES6+)**: Interactive search, dynamic components, and navigation.

## 🚀 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Karthika97510/TIMEZONE.git
   ```

2. **Navigate to the project folder**:
   ```bash
   cd TIMEZONE
   ```

3. **Open in browser**:
   - Double-click `index.html` to open it in your default web browser, or
   - Use VS Code **Live Server** extension for real-time live preview.

---

## 🌐 Enable GitHub Pages (Free Live Website)

To publish this website live on the web:
1. Go to your repository's **Settings** tab.
2. In the left sidebar, click on **Pages**.
3. Under **Build and deployment** > **Branch**, select `main` and `/ (root)`.
4. Click **Save**. Your site will be live at:
   `https://karthika97510.github.io/TIMEZONE/`
